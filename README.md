# StayLedger

Hostel Management System for Emarald Girls Hostel.

## Project Details
- Module: CS304.3 Advanced Database Management Systems
- Group: L
- Team Members: 10

## Technology Stack
- Frontend: React
- Backend: Laravel
- Database: MySQL

## Main Features
- User accounts and role-based access
- Resident management
- Floor and room management
- Room allocations and transfers
- Monthly fees and payments
- Outstanding balances
- Expense management
- Shared kitchen records
- Dashboard and reports
- Audit logs

## Folders
- frontend/ - React application
- backend/ - Laravel application
- docs/ - Project documentation
